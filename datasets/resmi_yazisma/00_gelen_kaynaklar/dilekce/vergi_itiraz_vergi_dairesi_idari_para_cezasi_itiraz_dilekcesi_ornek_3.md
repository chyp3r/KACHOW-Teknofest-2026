# Vergi Dairesi İdari Para Cezası İtiraz Dilekçesi (Ornek 3)

Adana VERGİ DAİRESİ MÜDÜRLÜĞÜ'NE

Konu: İdari Para Cezasına İtiraz

Müdürlüğünüzün 20.05.2025 tarih ve 76473 sayılı yazısı ile tarafıma tebliğ edilen 29937 TL tutarındaki idari para cezasına itiraz ediyorum.

İtiraz Gerekçelerim:
1. Söz konusu vergi borcum 11.10.2024 tarihinde ödenmiş olup, ödeme dekontları ektedir.
2. Ceza tebligatında belirtilen süre içerisinde ödeme yapılmış olmasına rağmen, sistem kayıtlarına yansımamış olabilir.
3. 213 sayılı Vergi Usul Kanunu'nun ilgili maddeleri gereğince cezanın kaldırılmasını talep ediyorum.
